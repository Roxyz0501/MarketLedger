# Market Ledger

マーケット購入履歴をキャラクター別に記録する、Roxyz0501 の新規独立 Dalamud プラグインです。初期版 `1.0.0.0`、API 15。**公開プレビュー版です。ゲーム内での実購入は未確認です。**

## インストール

Dalamud設定（`/xlsettings`）の試験的機能から、カスタムプラグインリポジトリに次のURLを追加します。

`https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json`

保存後、`/xlplugins` で **Market Ledger** を検索してインストールします。共通リポジトリをすでに登録している場合は、追加登録は不要です。

[リリース・ZIP](https://github.com/Roxyz0501/MarketLedger/releases/tag/v1.0.0.0)

## 使い方

1. インストールした Market Ledger を有効にします。
2. `/marketledger` で画面を開きます。設定の「購入履歴を記録する」は初期状態で有効です。
3. マーケットで購入すると、成功通知を照合できた購入だけを記録します。
4. 「購入履歴」でキャラ、アイテム名／ID、リテイナー名／ID、購入ワールド、HQ/NQ、日付、税込金額を指定し「検索・適用」を押します。日付の終了日はその日を含みます。初期表示は直近30日です。
5. 日別・月別の「支出グラフ」で税込・税抜・税額を切り替えられます。累積表示、グラフ上の金額表示、期間別の金額表もあります。
6. 「検索結果をCSV出力」は適用済みの条件に合う**全ページ**を出力します。未適用の入力は出力に使いません。UTF-8 BOM付きで、カンマ・改行・引用符をエスケープし、表計算ソフトの数式として解釈される文字列を無害化します。

記録項目: 日時（UTCで保存）、キャラID／名前／ホームワールド、購入ワールド、アイテムID／購入時の正式名、HQ、数量、税抜単価、税抜合計、購入税額、税込合計、出品ID、リテイナーID／名前／都市ID。リテイナーは売主の**リテイナー**であり、所有プレイヤーの特定機能はありません。

税込合計 = 数量 × 税抜単価 + 購入要求に含まれる税額。税率の固定推定はしません。販売側に課される手数料は購入者の支出に含めません。

## 記録の範囲と保存

- 導入前、プラグインが無効な間、照合できなかった購入の履歴は復元できません。
- リテイナー名は直前に受信した出品情報から出品ID・リテイナーID・アイテム・品質・価格・数量を照合して保存します。取得できない場合は「不明」とし、金額の記録は継続します。
- 成功通知には出品IDがないため、30秒以内の同じキャラ・ワールド・アイテム・数量の購入要求が1件だけの場合に記録します。曖昧な場合は推測せず「照合できなかった通知」の数を表示します。この数には重複通知・失敗通知も含まれ得ます。
- ログアウトやキャラ／ワールド切替で未確定の照合状態を破棄します。表示するキャラと記録対象のキャラは独立しており、記録は常に購入者に紐付きます。
- Dalamudのプラグイン設定ディレクトリ内の `market-ledger.db` に保存します。「設定 → 保存フォルダーを開く」で確認できます。CSVはその下の `exports` に保存します。
- 外部サーバーへ履歴を送信しません。同じPCの同じ設定ディレクトリを使うキャラの履歴をまとめて閲覧できます。他PCとは同期しません。
- 書き込み失敗は画面に表示し、明示的な「再試行」で再保存します。未保存が256件に達すると記録を停止します。終了時は可能な場合に `recovery-*.json` を残し、次回「設定 → 未保存データを復元」で復元します。処理済みは `.recovered` として残します。出品IDと記録IDによる重複防止付きです。ディスク全体が書込不可の場合や強制終了時は未保存分の保全を保証できません。
- 購入記録は自動削除しません。バックアップ時はプラグインを停止し、DBと存在する `-wal` / `-shm`、設定、復元ファイルを一緒にコピーしてください。
- 別のゲームプロセスから同じDBに追記された場合は「再読み込み」で反映します。常時ポーリングはしません。
- グラフは購入のある直近366日／366か月を上限に表示し、購入のない区間は省略します。累積は表示区間内の合計です。上部の合計とCSVは検索条件の全件を対象にするため、366区間を超える場合は範囲が異なります。
- 日付は閲覧時のPC現地時刻です。SQLiteのOS依存の現地時刻関数を使わず、.NETのタイムゾーン変換を使用します。

## 言語

日本語、English、Deutsch、Français、한국어、简体中文、繁體中文に対応。「言語設定」タブで変更し、即時反映・保存します。初回のみゲーム言語→Dalamud UI言語→Englishの順に決定します。公開ランチャー言語APIは使用していません。保存済みの選択を起動時やキャラ切替時に上書きしません。

アイテム名は購入時のゲームデータから取得した正式名を保持します。UI言語を変えても過去のアイテム名は翻訳しません。フォントはDalamud提供のNoto Sans CJKを使用し、画面の文字に必要なグリフだけをキャッシュします。

## 実装・参照

2026-10-18、ユーザー指定により「新規の独立プラグイン」として開始。他プラグインのリポジトリを複製していません。

- [Dalamud](https://github.com/goatcorp/Dalamud) — goatcorp、AGPL-3.0。公開の `IMarketBoard.OfferingsReceived` / `PurchaseRequested` / `ItemPurchased`、プレイヤー状態・フォント・UI APIを利用します。Dalamud本体は同梱しません。
- [購入要求API](https://dalamud.dev/api/Dalamud.Game.Network.Structures/Interfaces/IMarketBoardPurchaseHandler/) と [購入結果API](https://dalamud.dev/api/Dalamud.Game.Network.Structures/Interfaces/IMarketBoardPurchase/) の契約を参照しました。
- 共有タブはRoxyz0501ワークスペースの `templates/Dalamud/StandardPluginTabs.cs` をそのまま使用します。表示順は購入履歴／支出グラフ／設定／言語設定／支援です。
- [BaitBeacon](https://github.com/Roxyz0501/BaitBeacon) — Roxyz0501、Apache-2.0。作者共通の言語ラベル・フォントAPI使用方法を参考にしています。外部作者のコードはコピーしていません。
- [CommandAtlas](https://github.com/Roxyz0501/CommandAtlas) — Roxyz0501。作者のテスト用ソフトウェアレンダラーを画面検証に再利用しています。配布物には入りません。
- Windows内蔵 `winsqlite3.dll` を使用。購入データを扱うための追加プラグイン、外部サービス、同梱ネイティブDB DLLはありません。
- アイコンはこのプロジェクトのオリジナルの図形アートです。

## ビルドと検証

Windows / .NET 10 / Dalamud SDK 15。標準のDalamud開発DLL配置を利用します。

```powershell
dotnet build MarketLedger/MarketLedger.csproj -c Release
dotnet run --project Tests/Tests.csproj -c Release -- test-results/core-new
dotnet run --project Tests/UI/UiTests.csproj -c Release -- test-results/ui-new
```

テスト出力先は毎回新しいディレクトリを指定してください。測定結果・未確認事項は `VALIDATION.md` を参照してください。ソース・ライセンス・リリースはこの個別GitHubリポジトリ、インストール用インデックスは共通Roxyz0501 Dalamudリポジトリで管理します。追加の前提プラグインはありません。

任意の支援: [Roxyz0501 on Ko-fi](https://ko-fi.com/roxyz0501)。プラグインからは支援ボタンをクリックしたときだけ開きます。
